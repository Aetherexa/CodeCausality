# CodeCausality

> **Trace change. Understand impact.**

CodeCausality is a local-first change impact intelligence engine for software repositories.

The core product question is:

> **If I change this, what else could be affected?**

Baseline scanning is deterministic and local. It does not require an LLM, an agent, or API tokens.

Project initialization is in progress on the `feat/v0.1-change-impact-core` branch.
