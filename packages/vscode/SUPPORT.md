# CodeCausality Support

## Report a bug

Open an issue at:

https://github.com/Aetherexa/CodeCausality/issues

Include:

1. CodeCausality version.
2. VS Code version.
3. Operating system.
4. Whether you used **Analyze Current File** or **Analyze Working Tree**.
5. The error message or unexpected behavior.
6. A minimal reproduction when possible.

Please do not upload proprietary source code, credentials, private repository URLs, or other sensitive information to a public issue.

## Feature requests

Feature requests are welcome through the same GitHub issue tracker.

For V1, priority is given to improvements in:

- repository understanding
- change-impact accuracy
- graph usability
- test recommendations
- architecture evidence
- performance and reliability

AI/MCP/Copilot integrations are intentionally outside the V1 Marketplace promise and are planned as later-version capabilities.

## Security issues

Do not publish sensitive security vulnerabilities as public issues. Until a dedicated security reporting channel is configured, use GitHub's private vulnerability reporting feature for this repository when available.

## Current V1 support scope

V1 relationship analysis is strongest for JavaScript and TypeScript repositories.
